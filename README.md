# Cybersecurity Labs

Portfolio de laboratoires de cybersécurité : sécurité web, réseau, Active Directory, détection et reporting.

Formation IFAPME Pentester (2026–2028) ; préparation CPTS et CDSA.

Tous les exercices sont réalisés uniquement sur des systèmes personnels, des laboratoires ou des cibles explicitement autorisées. Les études publiées sont anonymisées et ne contiennent aucun secret ni donnée client.

## Études de cas : projets réalisés

- [Présence Douce — architecture et sécurité applicative](case-studies/presence-douce.md)
- [Forgia Gaming — architecture web](case-studies/forgia-gaming.md)
- [Portfolio personnel — développement web](case-studies/personal-portfolio.md)
- [Cardan — architecture de harnais et agents IA](case-studies/cardan.md)

Ces études de cas présentent les responsabilités et les considérations de sécurité, sans revendiquer un audit indépendant ni exposer de données sensibles.
