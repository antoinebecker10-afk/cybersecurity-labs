# Active Directory Security Labs

## Parcours prévu

- Domaine, contrôleurs de domaine, OU et GPO
- LDAP, Kerberos, NTLM et SMB
- Utilisateurs, groupes et permissions
- Comptes de service et relations de confiance
- Principes de moindre privilège et durcissement
- Journalisation et analyse des événements

Les expérimentations seront réalisées exclusivement sur un laboratoire AD contrôlé.

**État :** programme de laboratoire, résultats à documenter.
