# Forgia Gaming — Web Architecture & Deployment

**Public site:** https://forgia-gaming.vercel.app/  
**Project type:** Studio / product presentation website

## Project contribution

- Website design, development and deployment.
- Structuring of pages and presentation of studio projects.
- Management of the public-facing web experience.

## Security and engineering considerations

For a public-facing site, relevant review areas include HTTPS, dependency management, exposed configuration, third-party integrations and safe handling of deployment secrets.

**Verification status:** This document does not claim these controls have all been independently tested. No audit result is presented.

## Portfolio boundary

Game projects, internal systems, unpublished assets and proprietary implementations are outside this public case study.
