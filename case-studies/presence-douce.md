# Présence Douce — Web Application Architecture & Security

**Public site:** https://présencedouce.fr/  
**Project type:** Website / web application  
**Role:** Design, development, architecture and security review

## Work performed

- Designed and developed the website and its application architecture.
- Considered security-critical areas throughout development, including database access, authentication, password handling and configuration.
- Structured separation of responsibilities between the website, database and external file/media storage.
- Reviewed password-entry and authentication-related security concerns.
- Considered SSH key and other credential exposure, with an emphasis on avoiding exposed secrets.

## Security approach

The approach emphasized security-by-design: identify sensitive boundaries, review authentication and data flows, reduce unnecessary information exposure and revisit critical configuration choices.

## What this does **not** claim

This is not evidence of a completed independent penetration test, a formal compliance audit, or a guarantee that the application has no vulnerabilities. Specific implementation details, test evidence and remediation status are not published here.
