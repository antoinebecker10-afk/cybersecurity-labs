# Defensive Security / CDSA Labs

## Méthode d'investigation

1. Formuler l'alerte ou l'hypothèse.
2. Construire une chronologie.
3. Identifier les sources de logs et les actifs concernés.
4. Corréler les événements.
5. Distinguer faits, hypothèses et incertitudes.
6. Documenter les indicateurs et la conclusion.
7. Proposer une remédiation et les mesures de détection.
