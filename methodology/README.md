# Méthodologie de pentest

1. **Autorisation et périmètre** : obtenir l'accord explicite, identifier les cibles, limites et contacts.
2. **Reconnaissance** : cartographier les actifs et technologies autorisés.
3. **Énumération** : identifier services, versions, routes et mécanismes d'authentification.
4. **Validation** : distinguer hypothèses et vulnérabilités confirmées ; privilégier les tests non destructifs.
5. **Évaluation du risque** : décrire conditions d'exploitation, impacts métier et techniques.
6. **Reporting** : conserver des preuves minimales, proposer des corrections réalisables.
7. **Retest** : vérifier les correctifs et documenter le résultat.
