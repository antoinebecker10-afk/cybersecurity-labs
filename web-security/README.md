# Sécurité des applications web

## Checklist de laboratoire

- HTTP/HTTPS : méthodes, codes, redirections et en-têtes
- Cookies : Secure, HttpOnly, SameSite
- Authentification : messages d'erreur, limitation de débit, sessions, réinitialisation
- Autorisation : contrôle d'accès entre rôles et ressources
- Exposition : fichiers publics, informations de débogage, chemins internes, source maps
- Configuration : CORS, cache et politiques de sécurité
- API : documentation publique, gestion des erreurs et contrôles d'accès

Pour chaque exercice : environnement, périmètre, hypothèse, méthode, preuve, impact, remédiation et retest.

**État :** méthodologie documentée ; résultats de laboratoires à ajouter.
